# プライバシーポリシー（草案）

> **注意**: 本ドキュメントは法務レビュー前の草案です。公開前に弁護士による確認が必須です。

## 取得する情報

### 利用者本人（子世代）
- メールアドレス、表示名、認証プロバイダ識別子
- 端末識別子、Push通知トークン

### 親（被介護者）
- 表示名、生年月日（任意）、居住地域（市区町村まで）
- 介護度、ケアマネジャー氏名・連絡先
- 服薬情報、医療履歴、生活記録（**要配慮個人情報**）

### コンテンツ
- 家族チャット内容
- AIに対する質問・指示
- AI生成出力へのフィードバック

## 利用目的

- 本サービスの機能提供（家族グループ運営、AIサマリー、医師連絡パック等）
- AIによる助言品質の向上（匿名化処理を経たうえで）
- 不正利用防止、セキュリティ運用
- 課金・料金請求（RevenueCat 経由）

## 第三者提供

- 原則として行いません
- 例外: 法令に基づく場合、生命・身体の保護に必要な場合
- 業務委託先（クラウド事業者、AIプロバイダ、決済代行）にはセキュリティ要件を課して提供します

## 業務委託先

| 委託先 | 用途 | 所在 |
|---|---|---|
| Google Cloud Platform | サーバー、ストレージ | 東京リージョン |
| Supabase | データベース、認証 | リージョン要確認 |
| Anthropic | 生成AI（Claude API） | 米国 |
| RevenueCat | サブスクリプション管理 | 米国 |
| Apple / Google | 課金プラットフォーム | 米国 |

## 越境移転

- Anthropic、RevenueCat、Apple、Google が日本国外にあるため、要配慮個人情報を含むデータが米国に送信される可能性があります
- 利用者は登録時にこの越境移転について同意します

## 保管期間

- アカウント有効期間中: 全データを保持
- アカウント削除後: 30日以内に本サービス側のデータを削除（バックアップから完全削除まで最大180日）
- AI API 側の保持: Anthropic のポリシーに従う（標準で30日）

## 利用者の権利

- 開示、訂正、追加、削除の請求
- 利用停止の請求
- 第三者提供の停止請求
- 請求先: privacy@（公開時に確定）

## 暗号化

- 通信: TLS 1.3
- DB保存: 要配慮個人情報（医療履歴、服薬、ケアマネ連絡先）は AES-256-GCM で application 層暗号化
- 鍵管理: Google Cloud KMS

## 子（未成年）に関する取扱い

- 利用は18歳以上に限定（登録時の生年月日確認）
- 被介護者（親）が判断能力に欠ける場合、子による代理同意で取得

## 改定

本ポリシーは予告なく改定される場合があり、重要な変更時はアプリ内通知で告知します。
