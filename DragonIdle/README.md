# ドラゴン育成放置ゲーム（Unity）

卵を孵し、ドラゴンを育て、留守のあいだも金貨が積み上がる放置ゲーム。
Unity の uGUI をすべてコードから組み立てているので、シーンやプレハブを触らずに、
プロジェクトを開いて再生ボタンを押すだけで遊べる。

## 動かし方

1. Unity Hub で **Add → Add project from disk** を選び、この `DragonIdle` フォルダを指定する。
2. Unity 6（6000.0 LTS）以降で開く。別のバージョンしか無い場合はそれで開けばよい。
   `ProjectSettings/ProjectVersion.txt` の版はあくまで目安で、開いた版に合わせて更新される。
3. どのシーンでもよいので **再生ボタン** を押す。カメラも Canvas も自動で用意される。

ビルド用にシーンを1枚残しておきたいときは、メニューの
**Tools → ドラゴン育成 → 起動シーンを作成** を実行する。`Assets/Scenes/Nest.unity` を作り、
ビルド設定にも登録する。セーブを消したいときは **Tools → ドラゴン育成 → セーブデータを消す**。

## 遊びかた

| 画面 | できること |
|---|---|
| 巣 | 育てているドラゴンが並ぶ情景。触るとなでられる。下で卵を孵し、育て、進化させ、放つ |
| 探索 | 4つの行き先へ送り出す。留守のあいだ巣では稼がないが、帰りに大きく持ち帰る |
| 施設 | 巣そのものを強化する。全ドラゴンにまとめて効く |
| 称号 | 32種の達成目標。取るたびに生産量が永久に上がる |
| 転生 | 巣を手放して竜魂を得る。次の周回が丸ごと速くなる |
| 記録 | これまでの歩みと、出会った35種の図鑑 |

右下の「なでる」ボタンでも、巣の情景のドラゴンを直接触っても、毎秒生産量の数秒ぶんが
すぐに手に入る。竜笛を建てると効きが良くなる。

## 仕組み

**生産量**　`種族の基礎値 × レアリティ倍率 × (1 + 0.13 × (Lv-1)) × 2^(Lv/30) × 個体値`
に、全体倍率（宝物庫・竜魂・属性シナジー・称号）を掛けたものが毎秒のゴールドになる。
30レベルごとに覚醒して生産量が2倍になるので、育てる価値は段階的に跳ねる。

**属性シナジー**　巣にそろっている属性の種類ごとに全体 +5%。同じ属性で固めるより、
散らして集めたほうが伸びる。

**孵化**　レアリティは重み付き抽選で、祭壇のレベルと竜魂の数だけ上振れしやすくなる。
レアリティが高いほど、出てくる種族のティア（★の数）も上がる。卵は孵すたびに高くなる。

**放置報酬**　最後にゲームを閉じた時刻との差から計算する。初期は上限4時間・効率50%で、
時の砂時計が上限を、寝床の宝が効率を伸ばす。

**探索**　行き先は枠ごとに固定で、選ぶのは誰を送るか。所要は10分・1時間・4時間・12時間で、
長いほど倍率がよく、帰還時に無料でレベルも上がる。送り出したドラゴンは巣の情景から消え、
生産にも属性シナジーにも数えられない。途中で呼び戻せば、進んだぶんだけ受け取れる。
経過は時計で測っているので、アプリを閉じていても旅は進む。

**孵化**　卵が揺れて割れ、生まれたドラゴンが光芒とともに現れる。レアなほど割れるまでの
溜めが長い。図鑑に初めて載る種族なら「新種発見」が出る。

**進化**　同じ種族が巣に2匹そろうと、ゴールドを払って同属性のひとつ上の種族にできる。
レアリティも1段上がるが、進化で届くのはレジェンドまで。神話は孵化でしか出ない。
レベルと個体値は良いほうを引き継ぐので、だぶった仔竜が無駄にならず、巣の枠を空けながら
強くなれる。ティア5が系譜の頂点。

**称号**　累計ゴールド、孵化数、最高レアリティ、図鑑の埋まり具合など32種の目標がある。
達成すると生産量が永久に上がり、転生でも消えない。すべて取ると合計で約 +200%。

**転生**　この周回の累計ゴールドが100万を超えると竜魂を得られる。
竜魂1つにつき全生産量 +10%、孵化のレア度 +2%。図鑑・称号・記録は引き継ぎ、
ゴールド・ドラゴン・施設は手放す。

## 音

効果音も実行時に合成している。五音音階の上に減衰する倍音を並べているだけなので、
音源ファイルは1つも入っていない。なでる・孵化・育成・購入・進化・称号・転生で鳴り分ける。
ヘッダー右上のボタンで消音でき、設定は `PlayerPrefs` に残る。

## セーブ

`PlayerPrefs` に JSON を1本置いている（キー `dragon_idle_save_v1`）。
15秒ごとと、アプリを閉じたとき・非アクティブになったときに保存する。

## 日本語フォントについて

UI は OS にインストールされた日本語フォントを実行時に探して使う
（游ゴシック、メイリオ、ヒラギノ、Noto Sans CJK など）。
エディタで遊ぶぶんにはこれで問題ない。

ただし **OS フォントはビルドに埋め込まれない**。実機や WebGL 向けにビルドするなら、
日本語フォントの `.ttf` / `.otf` を `Assets/Fonts/` に入れて、`UIStyle.MainFont` が
それを返すように差し替える必要がある。TextMeshPro を使う場合は、
同じフォントから Font Asset を生成し、必要な文字セットを含めること。

## バランスを確かめる

`./Tools/simulate.sh 30` を実行すると、UI を通さずにゲームのロジックそのものを1秒刻みで
30日ぶん回し、時間ごとの毎秒生産量・巣の数・最高レベル・転生見込みを表にする。
数字をいじったあとに詰まりや行き止まりが出ていないかを、遊ばずに確かめられる。
mono の `mcs` と `mono` が要る。

いまの設定では、初回転生が見えるのが1時間前後、巣が埋まりきらないまま30日目でもまだ
伸びしろが残る。宝物庫と訓練場と祭壇は上限に届かず、時の砂時計・竜笛・寝床の宝は
数時間で上限に達する（それぞれ効果に自然な頭打ちがあるため）。

## Unity を開かずに検査する

`./Tools/typecheck.sh` を実行すると、`Assets/` 以下の C# を `Tools/UnityStubs.cs`
（Unity API の最小スタブ）とつき合わせてコンパイルし、綴り間違いや引数の数の食い違いを
その場で見つけられる。mono の `mcs` が要る（`apt-get install mono-mcs` など）。

`Tools/` は `Assets/` の外にあるので Unity は読み込まず、スタブがビルドに混ざることはない。
スタブの `Mathf` や `PlayerPrefs` は実装が入っていて、そのままシミュレーションにも使っている。
ただしスタブは実物ではないため、ここが通っても Unity での動作までは保証しない。
一次検査として使い、最終確認はエディタで行うこと。

## ファイルの構成

```
Assets/Scripts/
  Core/
    Bootstrap.cs       再生と同時にカメラ・Canvas・GameManager を用意する
    GameManager.cs     状態と計算のすべて。数値の決定はここだけが行う
    SaveData.cs        保存される形。ここにある値だけが引き継がれる
    SaveSystem.cs      PlayerPrefs への読み書き
    Sfx.cs             効果音の合成と再生
    NumberFormat.cs    万・億・兆…の位取り表示
  Data/
    Element.cs         7属性と色
    Rarity.cs          5段階のレアリティと倍率
    SpeciesDatabase.cs 35種族。属性ごとにティア1〜5
    UpgradeDatabase.cs 7つの施設と価格の伸び
    ExpeditionDatabase.cs 4つの探索先と所要時間
    AchievementDatabase.cs 32種の称号と永久ボーナス
  UI/
    UIStyle.cs         配色・フォント探索・角丸スプライトの生成
    DragonArt.cs       種族ごとの姿を距離場から実行時に描く
    NestScene.cs       巣の情景。ドラゴンが並び、息をし、触れる
    HatchReveal.cs     卵が割れて生まれるまでの演出
    FloatingText.cs    ふわりと浮かんで消える数字
    UIFactory.cs       uGUI をコードで組み立てるための道具箱
    GameUI.cs          ヘッダー・タブ・なでる・通知・復帰画面
    TabView.cs         タブ1枚の基底
    NestTab.cs         巣
    ExpeditionTab.cs   探索
    FacilityTab.cs     施設
    AchievementTab.cs  称号
    RebirthTab.cs      転生
    RecordTab.cs       記録と図鑑
Assets/Editor/
    DragonIdleMenu.cs  起動シーンの作成とセーブ削除
```

数値の調整は `GameManager.cs`（倍率と価格の式）と `UpgradeDatabase.cs`（施設の効果と価格）に
集めてある。UI 側は計算をせず、表示だけを担当する。
